# 交互属性关联

读取本用例SSD、系统组成、对象支持操作和已验证API映射/参数表。根据组件ID和明确接口标识关联，不根据相似名称猜服务归属。按请求/返回方向选择参数，对当前交互的数据序列与对应API要求取有据并集；保留两侧独有字段、类型、必填性、默认值及独立约束来源，不做需求一致性检查、不为消除差异新增交互。同名但不同位置的数据不合并；不同类型要求均保留，任一来源明确必填则保留必填要求，不同默认值只展示来源。派生产物parameter_requirement_sources保存来源明细，原始SSD和API表不改写。

输出仍为发送方、操作、数据、接收方以及展示需要的组成位置、支持操作和字段属性。未知项待确认，不能补造HTTP地址、类型或阈值。对象支持写入不代表本次读取需要分析写入异常。

主要由确定性工具完成，歧义进入待确认，不额外调用模型重复抽取已验证表格。
