# 逆向抽取检查

逐项核验全部输入单元，不读取其他G/E/T集合。检查原文支持、原子原因、实际交互定位、关注点与规范化代码一致性，保存精确原条件引句及理由。保留原文ID和未映射记录，不能让宽泛关注点名代替具体机制。

对明确报告的unmapped，仅可确认记录保留与映射缺口正确；不得将其改为已匹配。测试框架推导必须有原始异常引句及不同因果触发依据，不能称为客户明示；普通正常条目不能展开异常。生成单元必须保持原有效挂载，不作适用性筛选。

返回每个unit_id一次，source_supported、atomic、mapping_correct、cause_correct明确布尔，包含原文依据与warnings。实际语义错误拒绝，未知来源边界单列警告，不修补或删除原始场景。
