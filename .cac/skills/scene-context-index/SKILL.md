# 文档索引与上下文取片

输入为原始RR、SR Markdown。工具一次解析标题层级、原始行号、内容指纹及章节ID，导出source-index.json。索引保留历史/AR附录供查看，但default_input=false的章节不进入默认RR/SR建模。不能删除原文件。

按已确认用例目录的source_ranges选取对应RR/SR段落，不读相邻用例；接口参数任务按接口索引取片。无法确定范围时待确认，不静默退回全文。证据只用当前输入给定的evidence_id，程序恢复引文，不能自己改引文、行号或来源。

这是工具任务，无需LLM。索引不含测试异常，不能向建模器泄露GT/E。章节索引不等同于已完成语义抽取。

## 用例身份取片

`ssd-context` 工具按本组 RR/SR 正向正文中的对象名称及精确来源范围，选择相关组件并保留所属边界。其输出含本组 RR、SR、case-group 和组成身份子集；不携带其他用例的组成关系。无法确定身份时等待确认，不回退全量图。模型只读取这一产物，原始文档和完整组成图仍可查看。
