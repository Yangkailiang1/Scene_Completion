# 风险保底推荐

输入：缺失报告M、模式适用性产物、冻结的项目模式/风险/阈值/K设置、执行前已人工审核历史。禁止读取GT、当前评测答案、未经审核机器输出作为历史。

使用工具排序，无需模型：
- 仅M中达到证据阈值的异常候选；正常、可选、不适用及待确认不进入正式Q。
- R：低/普通/高/关键=0.25/0.5/0.75/1。项目可覆写且记录依据。
- H：按功能、技术特性、实际操作、调用边界、数据方向、明确时效检索相似已审核案例；Beta(1,1)中性先验，无历史为0.5。
- 默认0.7R+0.3H。同分优先不同模式，最终稳定ID。K默认10；全部关键项强制纳入，超过K明确解释。
- 同次运行和同用例反馈不得参与本次排序；未审核/暂缓/已覆盖不作负反馈。模式版本不兼容的历史不直接复用。
- 关键低置信及模式定义缺项单列业务待审，不入Q。

输出：gap-recommend.json/Markdown含Q、全部候选优先级、风险/历史依据、关键待审、保底理由及设置/历史快照。网页审核不改冻结GT或当前排序，只形成下一轮可用历史。

GT仅在排序完成后由独立评测工具读取：|Q∩GT|/|Q|、|Q−GT|/|GT|（可能超过100%）、关键缺失召回率；人工采纳率另列。旧运行显式关闭时仍返回enabled=false、status=未启用。
