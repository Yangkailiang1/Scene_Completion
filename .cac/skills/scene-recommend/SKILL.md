# 场景推荐

从完整比较结果读取未匹配候选；部分匹配按项目口径计重合，不进入未匹配推荐集。
Agent 或 embedding 后端均保留全量候选、支持度、缺失度、加权分数及依据。
标注为推荐评分，不是校准概率；相关主题不能自动证明异常合理。
Agent 的高支持度需独立复核证据量表，并保存支持约束原句；只有具体接口背景时上限 0.5，
仅主题相关时上限 0.25。该复核仅影响推荐分项，不过滤生成场景。

可用 rerank 对 embedding 召回的最多 20 段需求/设计证据精排。
仅增强推荐，不改变候选和指标；失败时停在未完成状态，不隐式替换后端。
分别给出证据章节和建议补充章节，无法定位时明确说明。

新协议见 ../scene-check/references/three_roles.md。本 Skill 不调用其他 Skill。
