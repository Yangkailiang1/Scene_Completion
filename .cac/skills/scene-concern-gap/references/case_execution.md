# 按用例执行与诊断修复

诊断优先用`evidence_refs`选择工具提供的逐字引句ID，工具还原原句；直接引句必须属于原始字符串，不使用Python字典转义后的表示作原文。诊断格式最多两次独立尝试并持久计数，失败进入`diagnosis_blocked`，保留原失败对象及已预留语义轮次，不把诊断错误替换成上游生成缺陷。不得通过反复生成正常模型或G绕过诊断协议失败。

来源审查仅有行首缩进差异时，工具可还原精确原句并保留原引文；不得改变正文、标点、顺序或内部空白。`revalidate-source-audit-format --output-dir <run> --use-case-id <ID>`只离线复检真实旧执行，保留修复计数，仍由原校验器和调度器决定通过；不用于覆盖语义拒绝或绕开修复上限。

图检查的局部交互ID只有在原包内唯一对应时才可解析成完整ID；`revalidate-graph-format`离线复检旧执行，缺项、歧义及语义缺陷不能自动补齐。语义输入、指令及输出契约相同而工具元数据变化时，当前校验器复验后复用成功任务，保留原包和执行证明；共享组件缓存位置变化不使原图检查失效。`revalidate-cached-task --output-dir <run> --use-case-id <ID> --stage <阶段>`可显式进行同样的零调用复检，不改变修复预算。

校验报错应指出每个受影响组件/条目、字段及来源，避免只返回首个笼统错误。工具修复了诊断信息后，可用`refresh-task-diagnostics --output-dir <run> --use-case-id <ID> --stage <阶段>`从原失败执行零调用重算错误。只有因重复错误提前停止、诊断确实变化且未用满两轮时，才继续剩余预算；不得重置计数或将此入口作为额外语义循环。

客户低并发环境先用并发1。429触发共享冷却并遵守Retry-After，续跑保留尚未到期的冷却；504、超时、断连不盲目重投相同POST，保持传输待处理，不消耗语义修复轮数。可配置`max_context_tokens`，工具在发送前按保守UTF-8字节代理及输出预留检查容量；超过时要求按阶段拆包，不能截断证据。该估算不是提供方精确token计数。

需要测量和优化阶段耗时时，见[performance.md](performance.md)；`--profile`记录独立计时，`--history-run`仅复用其他用例的已核验E历史库，不能成为建模或测试结果复用通道。

默认 `scene-pipeline --execution-mode case-dag --auto-repair bounded --max-repair-rounds 2`。准备包模式仍不主动请求模型；使用同一输入、配置及输出目录续跑。阶段兼容编排用 `--execution-mode stage-barrier`。

工具就绪队列按下游推进、失败修复、新用例抽取轮转。每个用例只依赖自己的正常模型、实际组件检查、SSD及参与者检查；E/T抽取独立提前执行，交互定位等本用例SSD通过。每个阶段的当前输入、成功执行与修复预算写入 `case_tasks.json`；任务运行、修复中、待确认、额度/修复预算耗尽和过期保持区别。全局外部调用遵守配置的共享并发上限，默认1；不能在各用例里另开worker绕过上限。

失败先诊断，再做定向修复或新检查，最后用原校验器复检。格式、引用或结构错误只修实际错误的包；语义错误只读本阶段原包允许的原文/契约。保留未受影响的成功条目和原执行ID/哈希。误判须引用原文复核依据，新模型检查结果才可改变结论，不能手写通过。相同失败无进展提前停止；最多两轮且续跑不重置，不能另开人工语义循环绕开预算。

正常模型、特性、关注点、G修复不得读取E或GT；E/T修复各自独立。缺信息继续待确认，不虚构接口、阈值、响应或恢复。原文冲突或新组件/调用/关注点/原始spec修订列出原句、章节、位置和影响，等待用户确认，其他用例继续。确认绑定提案及来源证据；无关新增项不撤销原确认。

查看 `progress.json/md`及各用例目录的局部结果；局部Excel/Markdown没有正式全项目指标。已检查去重的历史E立即做embedding缓存，历史全部齐全后才固定历史库并计算推荐排序和正式四指标，T始终不进入历史库。传输重试保持配置；额度耗尽停止新外部调用，但缓存校验、局部导出仍可继续。

用 `check-interaction-run --output-dir <run>`核验各通过任务的来源、原包、实际执行、依赖哈希与结果。失败清单与有效用例产物一起返回。修复入口可加 `--use-case-id <ID>`限定用例；再次运行原流程命令推进剩余下游。离线快照只声明重建结果，不冒充新的模型执行验收。
