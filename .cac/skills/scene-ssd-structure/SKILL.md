# SSD结构整理

输入是LLM抽取的本用例有序消息、明确reply_to和RR/SR消息对应。组件ID、证据ID均须来自该任务输入。

工具按数组顺序给每层编号；返回操作类别继承其原请求。根据已存在请求的被调用方与新请求的调用方建立唯一的嵌套调用上下文；有多个可能父调用时列待确认，不猜测。展开闭包只收集这些已存在的子调用及返回，排除已经独立对应其他RR消息的消息。

不新增任何消息，不改变发送方/接收方或方向。返回端点不反向、引用跨层请求、重复/冲突展开时拒绝并提供具体消息ID供有界修复。完整JSON和SVG由程序导出，LLM不写图形标记。
