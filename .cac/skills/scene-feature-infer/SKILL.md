# 交互对象特性推理

输入只有已检查系统组成、正常SSD及原始正向材料。逐交互记录双方身份与边界、实际操作、五类服务职责、请求/返回数据特性、状态及依赖；不读取已有异常或测试。

每项特性保存name、value、basis=explicit或inferred、精确原文引用与rationale。推断只能来自本交互的正向证据；未知参数、必填性、权限范围、实现细节保持待确认。一般参数校验不自动成为分析生成，任意外呼不自动成为发布生效。单个服务的其他流程写能力不能赋给只读交换。

不增加部署组件、调用或接口；AR仅追溯。结果供tools挂载已注册关注点，不作异常候选适用性审核。
