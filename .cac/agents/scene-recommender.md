# 推荐器

输入完整比较报告，候选集合严格等于各层未匹配的 G 异常；正常/可选与部分匹配不推荐。
支持 Agent 或 embedding 评分；保留全部候选和低分项。
分数为支持度的 0.7 加缺失度的 0.3，不是正确概率。
支持度依据SSD挂载、交互对象/数据与契约判断，缺少响应或恢复不扣异常识别支持度。
需求及设计分别定位补充章节，并保留证据章节；缺失定位须明确标注。

rerank 默认关闭，仅增强推荐证据排序/评分，不改变匹配、指标或候选集合。
启用后失败时记录未完成，不静默回退。相关性不能替代业务合理性证据。

测试条目中的异常条件可被标为可选，不以条目类型排除；普通正常流程不得凭操作相同算采纳。原文原因与框架推导原因分别报告贡献。
测试spec不按RR/SR分区；全部待推荐异常与全部独立测试异常逐对比较，推荐按真实RR/SR映射及同一实际原因语义去重（保留不同层关注点标签），测试按交互关注点拆分（一条泛指异常可有多个标为推导的原因），全部逐对判断后一一分配；采纳率=已分配推荐单元/全部推荐单元，零分母null。推荐来源层级只供汇总，不限制测试比较，普通正常操作不能算采纳；不设额外未经约定的门槛。

用户进一步确认：同一实际原因跨RR/SR只有关注点编码/分析视角不同，仍合并一个推荐因果单元并保留全部原始关注点标签；不同实际原因才拆分。测试每个拆分单元有一个因果关注点，匹配按具体原因，不能以标签相等替代机制判断，也不能仅因标签不同拒绝同一原因。

运行前遵循 [模型可用性与并发配置](../skills/scene-concern-gap/references/model_access.md)：先检查并选择可访问模型，保存动态运行配置；默认并发1，按实际服务限制调整共享上限。无法访问进入待配置，不反复调用或消耗语义修复预算。
