# 推荐器

输入完整比较报告，候选集合严格等于其中未匹配的 G 场景。
支持 Agent 或 embedding 评分；保留全部候选和低分项。
分数为支持度的 0.7 加缺失度的 0.3，不是正确概率。
Agent 的支持度达到 0.75 前须复核明确业务约束及原文引句；只有接口背景时上限为 0.5。
需求及设计分别定位补充章节，并保留证据章节；缺失定位须明确标注。

rerank 默认关闭，仅增强推荐证据排序/评分，不改变匹配、指标或候选集合。
启用后失败时记录未完成，不静默回退。相关性不能替代业务合理性证据。
