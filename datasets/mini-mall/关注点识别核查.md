- 已识别安全规则恢复有来源的activation guard；条件明确但通用value为空不再误作规则未知。
- API JSON分别接入请求、成功响应和失败响应，失败字段不混入成功响应。
- 字段约束按独立分句解析，长度不误作数值范围，枚举保留离散集合。
- 按实际交互拆分识别；返回分片也过滤无关文档、规则及实体上下文。
- CRUD支持已证据化的delegated模式和下游调用定位。
