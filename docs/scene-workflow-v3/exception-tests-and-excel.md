# 异常测试集、Excel与独立补全

规则版本：`exception-only-tests-20261025-v3`。协议保持scene-workflow-v3；旧报告不改写。

## 指标与场景类型

生成有效率为完整匹配的G数量除以全部异常G，缺失异常漏报率为未命中的GT缺失项除以GT缺失项。只用完整失败对应计分，分类差异和处理行为另记。GT数量除以G数量只是当前一一匹配的集合规模上限，不是质量指标。

测试类型从表格“类型/场景类型”列读取，不能搜索整行关键词。异常参与GT；正常、可选及未知类型不参与，仍可在测试集查看。未知类型保留待确认。原文E和G也排除普通取消、正常成功和仅有恢复结果的场景。集合无匹配记录在没有非空/必有结果约定时是允许的可选结果；指定资源不存在另行判断。

Markdown历史9列表保持兼容。自定义列及Excel保留表头映射。Excel不执行公式，拒绝公式单元格、宏和外部链接。5MB上传限制，40MB解压总量限制。测试ID使用TEST-或SUP-开头的唯一编号，无效编号拒绝导入而不静默丢弃。表格预览核查必填项、重复测试ID、类型计数和文件/工作表/单元格坐标。

## 原始与扩展测试集

`test-ground-truth`仅处理原始异常测试。独立任务`test-supplement`只可见正向SSD、正常接口约束、去除violation的正常规则、现有异常测试目录和项目关注点。不能携带G/E/缺失报告/匹配答案；接口用工具构造单字段单约束测试，业务语义由scene-test-supplement处理。实际测试的触发、前置、步骤、预期、可执行性及依据均独立保存。

业务补充按单条正向规则独立执行，接口字段规则由工具处理。补充测试先通过Schema、来源和交互校验，再转换为独立自动GT。有界修复后仍未通过的候选保留在pending，原始模型响应可追溯，不进入GT或指标分母；页面测试集和待确认项均可查看。业务补充必须选择同一交互的normal_rule_id，已知交互、分类和引文由工具回填。字段约束不由模型补造，未知标准仅能保存条件级。GT_self先在补充集内部比较同一失败并保守去重（完整对应团，不按传递链猜测合并）；GT_dedup再比较补充GT和原始GT，不读取G/E；完整同一失败保留原始ID并记录合并。test-expanded形成扩展集合。原始和扩展集合各自保存GT/G与GT/E对应，再计算同样公式。页面默认扩展，可切换原始。机器补充并非全部人工确认，也不表示这些测试已在业务系统执行。

新网页运行和CLI流水线默认补全；CLI可用`--no-supplement-tests`仅运行原始测试。底层执行器只有显式config.supplement_tests=true才增设任务，以保留旧离线调用方的兼容。新增测试不修改原始test_spec。切换测试文件产生项目级版本并归档旧报告，切换后旧指标明确标为待重算。

## 文件与接口

模板：examples/tests/mall-exception-tests.xlsx。包含原始异常测试、机器补充异常测试及填写说明。类型可编辑；业务需在实际执行前补齐未知数据和条件级标准。

- POST /api/test-sources/preview：sources数组；Markdown为name/content，XLSX为name/content_base64。返回记录、类型计数及导入问题。
- GET /api/test-sources/template：下载可编辑示例。
- GET /api/projects/{id}/test-sources：当前版本、历史版本、当前输入预览。
- PUT /api/projects/{id}/test-sources：携带expected_version及sources，或version切回旧版。运行时拒绝修改，版本冲突拒绝覆盖。
- GET /api/projects/{id}/test-sources/supplement?case=...：按用例读取已保存补充测试；未完成不冒充空集合。
- results/metrics及results/{case}支持test_set=original/expanded。原始计分保存在original_evaluation，扩展保留独立集合哈希、来源和去重记录。

## Token优化及缓存

已有任务已经按分支/交互分片，继续切小会增加重复Schema和注册表开销。本轮绑定只传交互身份/操作索引，不反复传全部正常规则。E按已绑定交互取参数；GT保留全部候选身份索引，详细字段和规则按测试明示对象取片，不能因筛选丢掉候选交互。

比较保留单对缓存和结构排除，明确字段约束由独立工具事实确定后可精确匹配；输入/返回、字段、规则种类和值不同不能借此合并。模型只判断未决对，分批同时受32对及输入字节预算约束，字节不是Token。语义原始响应以输入/Skill/Schema/模型/指导独立缓存，每次读取重验；工具规范化再运行，展示变化不重调模型。

用量页直接展示任务类别/角色/模型/用例的输入、输出及其中思考，复用次数与扣费请求分开。历史累计与执行轮增量分别查询，失败无usage保持未知，实际费用无账单依据不写成0。旧模型预算不重置，新模型仅依据用户确认建立独立窗口。
