# 实际依赖与可并行任务

```mermaid
flowchart TD
  RR[RR Markdown] --> IDX[章节索引 工具]
  SR[SR Markdown] --> IDX
  IDX --> RC[RR目录元数据取片 再抽取用例]
  IDX --> SC[SR目录元数据取片 再抽取用例]
  RR --> C[系统组成]
  SR --> C
  SR --> AM[API映射]
  AM --> AI[接口索引 工具]
  AI --> P[各接口参数子任务 并行]
  P --> AP[完整API参数表]
  RR --> EB[原文已有异常分支]
  SR --> EB
  RC --> A[用例对应]
  SC --> A
  A --> CTX[本组正向正文与身份取片 工具]
  C --> CTX
  CTX --> F[每组一次语义抽取 精简完整SSD]
  F --> STR[顺序和引用整理 SVG绘制 工具]
  F --> V[RR/SR显示视图]
  V --> O[对象支持操作]
  T[测试spec操作投影] --> O
  C --> O
  O --> I[融合具体交互补全]
  AM --> I
  AP --> I
  F --> I
  I --> K[预定义关注点匹配]
  K --> G[生成异常G]
  F --> B[原文分支绑定具体交互]
  EB --> B
  B --> E[关注点逆向归类与细化E]
  AP --> E
  G --> M[覆盖比较与缺失M]
  E --> M
  TS[独立测试spec异常] --> GT[绑定融合交互并细化GT]
  F --> GT
  AP --> GT
  GT --> EV[独立指标评测]
  G --> EV
  E --> EV
  M --> R[可审核缺失报告]
```

图上的用例对应、系统组成完成后，完整SSD即可执行，不等待API映射／参数结束。原文异常分支与正向抽取并行，E和GT的逆向细化只读取各自通道、融合SSD及正常规则，不读取G。

调度器在依赖完成后动态注册用例和接口子任务；每个任务使用独立缓存、审核与修复状态。前端相同依赖层并排布局，不为视觉排列新增依赖。未展开的用例步骤以虚线流程预告展示，不计执行进度。推荐器待定且未启用。
