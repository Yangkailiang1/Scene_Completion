# 项目级关注点与待确认项

工作台的入口是工作区、最终结果、待确认项、关注点设置、用量与费用。配置、导出和执行模式统一收在“更多操作”。管理页使用整个工作区；普通阅读默认84%工作区和16%任务导航，可拖动或专注阅读。审核页不再保留大块装饰性标题区域。

## 待确认项

待确认项按来源区分正向建模、原文已有异常E和独立测试GT，不因文字相同合并不同通道。可以按用例、来源、状态及关键词筛选。展示具体交互、对象/字段、原文行号和来源节点。

默认队列仅展示异常及归类疑问。关注点匹配的未声明规则单列为诊断；SSD及交互补全的问题单列为结构核查；执行失败和阻断提问单列为执行问题。记录全部保留，但不将缺少依据、操作尚未对应等内部状态当作已发现异常。规则及结构诊断须在来源节点补充依据或核对模型，不要求业务逐条判定是否为异常。相同文字的诊断与业务候选也不会合并。

本次商城运行的1131条未处理记录中，932条是关注点规则诊断，140条是结构核查，59条是异常及归类疑问；另有1条用户已确认跳过的正常规则候选。这是审核记录数，不是异常数或评测分母。

业务可选择是异常（选择启用的具体关注点）、不是异常/跳过或待补材料，并填写依据。审核不自动调用模型、不改写既有报告；意见持久化到来源节点，后续在该节点重新执行时使用。不把E或测试答案传播到G。模型阻断问题和技术失败也统一展示，但需回来源节点处理，不将技术错误直接判作业务异常。

`pending_decisions.json`保留最新判定和全部历史，含条目快照、定义哈希、来源节点、审核版本及时间。判定绑定当前候选ID，候选内容变化后不静默沿用旧判断。

## 项目定义版本

每个项目初始化时冻结默认模板，后续模板升级不自动改变已有项目。定义包含稳定ID、名称、说明、层级、功能/技术分组、父关注点、适用操作和适用依据。名称可编辑；内置数据检查使用稳定ID识别，重命名不会破坏类型/范围等检查。

新增、修改、停用和恢复生成新版本。删除采用停用，历史定义仍可解释旧产物。存在启用子项时须先调整继承，禁止循环。数据、人类和服务关系关注点使用对应命名空间，五种功能分类及数据库/LLM身份沿用当前框架。

发布新定义不自动重新评测。下一轮只因定义及实际依赖变化重算分析节点，组成、API等无关抽取不因定义编辑强制重做。执行使用的定义被冻结；定义变化后重算前，将旧缺失报告、任务状态和清单归档到`run/report_versions`，可在历史定义页下载对应报告。未知具体规则不会因定义存在而变成确定异常。

## 接口

- `GET/PUT /api/projects/{id}/registry`：查看/发布项目定义。写入携带expected_hash；GET可指定version。返回历史版本及关联报告。
- `GET /api/projects/{id}/pending`：分页筛选（queue、status、case、channel、search、offset、limit）。queue默认business，另有rules、structure、technical及all，返回分队列数量。首次增量索引读取当前有效产物，后续复用派生索引。
- `POST /api/projects/{id}/pending/{item_id}`：提交choice、concern_key、note及当前revision。不触发模型请求。

项目注册表通过ContextVar在执行和请求范围内隔离，线程任务继承本轮冻结上下文；没有进程级全局字典替换。注册表内容哈希进入分析缓存身份。修改不能影响同时执行的其他项目。

## 最终结果

按需加载用例，按融合SSD的实际交互顺序展示发送方、操作、数据、接收方，并列展示需求已有异常E、生成异常G及独立测试GT的关注点和具体触发条件。可展开原文、明示/推导属性、异常步骤、既有后续行为及保存的匹配结果。G缺失标记来自已有M，不在页面重新计算。未绑定项保留单独显示；未完成不等同空集合；GT仍需业务审核。

图表总览列出项目共享及当前用例已保存的系统组成图、融合SSD、RR/SR视图和各表。SVG支持缩放和下载，JSON/Markdown/DOT按实际文件提供；未实现的架构图不补造。只展示当前有效父任务的正式文件，排除旧的失效子任务。定义名称读取执行时冻结的registry_used快照，不用之后编辑的定义重写历史。

已完成项目不保持全局SSE连接或高频轮询。运行中的首次SSE使用tail=1取得当前游标，不重播所有历史模型输出；重连仍遵守Last-Event-ID，节点历史通过独立分页接口读取，原始记录不删除。

- `GET /api/projects/{id}/results`：轻量用例目录、完成状态、实际图表文件目录。
- `GET /api/projects/{id}/results/{case_id}`：单用例交互、E/G/GT、M标记、未绑定项、冻结定义及已有指标/匹配；不调用模型，也不重新匹配。
