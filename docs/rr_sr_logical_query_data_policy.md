# 逻辑查询结果的来源协议

用户已确认：正常流程明确查询或读取、但未列返回字段时，允许记录查询对象的逻辑结果，注明依据查询语义推导、具体协议结构待确认。这不授权新增组件或调用边。

新生成输入使用 `logical-query-results-v1`。每项推导返回数据保存 `field`、`derivation_reason`、连续原文 `evidence_quote`、绑定交互的同层 `source_refs`、`protocol_structure_unknown=true`。模型和 SSD 保留标记，图中展示“查询语义推导（协议结构待确认）”。原文明示字段与推导对象分开追溯。

工具检查实际 read 交换、字段成员、引用范围、同层正常来源、原文引句和独立来源检查的逐项映射。来源检查从原文重新判断 `explicit` 或 `query_semantics`，未核实、未标记或越界的推导阻止正式验收；工具不能代替语义判断。旧模型不被自动补标为新协议。

禁止推导 JSON 成员、类型、布尔结果、参数限制、额外调用或异常条件。服务本地所有权校验、内部保存值不自动成为返回。推导逻辑对象不能作为接口字段限制的证据，生成异常仍只能沿真实 SSD 关注点挂载产生，不读取检查器或测试补写场景。
