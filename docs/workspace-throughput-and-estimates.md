# 工作区实时吞吐、模型切换与剩余时间（2026-10-29）

工作区顶部“实时监视”默认折叠成一行，包含当前可测吞吐、预计剩余时间、切换开关状态。展开可查看节点请求、低速判定策略、候选模型、切换/限流时间线和吞吐变化报表。点击节点定位输出；“切换策略”进入项目模型设置。图表支持账号、模型、节点和正文/工具参数/公开推理内容筛选，导出PNG、SVG、CSV、JSON。执行监测JSON另含估算依据及当前策略。

## 测量口径

- 每次流式HTTP请求持续统计可接收内容；窗口速率是UTF-8字节÷4估算，包含网关公开的推理字节，不是供应商账单Token。
- 实时摘要每3秒刷新，执行器通常每5秒记录流内速率。没有返回可测内容、或采样超过15秒未更新时显示未知，曲线遇到超过15秒的采样空档断开，不用直线填补；不能把历史最后速率冒充当前速率，也不能把未公开推理当作0Token。
- 同一请求累计字节与窗口速率分开，服务/节点排队与实际生成区分；校验工具工作不展示为模型正在生成。服务停止或旧请求无结束事件时，不将它冒充活跃请求。
- 报表按当前执行轮的起始时间加载，避免初次打开扫描全部历史；用量与费用中的原图仍可查看历史。前端请求互斥和事件ID去重，防止慢网络下轮询重叠。

## 可配置切换

沿用既有执行器，默认2估算tok/s，生成宽限60秒，窗口30秒，连续2个低速窗口触发；或120秒没有可测输出。默认最多切换2次，降级模型冷却300秒。所有参数可在项目模型设置调整；在途流式策略定期重新读取配置，下一次请求重新解析路由。没有候选或允许切换次数为0时只监测，不主动取消有用请求。

只有显式启用和配置的候选可被尝试，仍须通过账号允许列表、独立额度和并发保护。所有项目及Agent合计最多3路请求，429仍按现有机制退避/降并发。关闭本地流不保证上游停止计费；未知用量继续保守记录。已通过产物不因速度阈值或模型配置改变而失效；只重做当前未完成节点。不能用残缺JSON作为成功结果。

## 项目预计时间

只基于当前已发现的真实DAG，不按“已完成百分比”线性推算：

1. 按阶段收集已有成功节点的真实起止耗时，取最近最多40个样本。
2. 使用阶段耗时的20/50/80百分位，结合实际依赖、当前运行节点剩余时间和生效并发上限模拟调度。
3. 显示典型区间及低可靠性标记。单阶段样本少、节点已经超出历史耗时、流式数据过期时明示限制，区间不是统计置信区间。
4. 未发现后续用例/分片不作为已知工作；新阶段没有样本时暂不提供整个项目的完成时刻。人工审核、业务回答、配置/技术阻塞、未来未知重试不预测墙钟耗时。暂停时只显示恢复后的自动执行净时间。
5. 运行中根据当前状态重新估算；已确认的限流降并发使用effective_max，而非旧的最大并发。其他项目或管理Agent共享网关仍可能延长时间。

接口：`GET /api/projects/{id}/execution-monitor`（只读）；`GET /api/projects/{id}/throughput?since=...&after=...`返回同时间范围内的脱敏数据。接口不返回凭证、消息、工具参数正文或思考文本，不调用模型，不改写业务产物、审核状态及额度账本。

## 验证

后端覆盖并行依赖调度、无样本/循环/人工阻塞/暂停、不完整历史、采样过期与未知速率、限流降并发、低速到候选切换、原模型标识记录、空候选不取消、来源脱敏及按执行轮筛选。前端覆盖折叠报告、按需图表、节点定位、未知/阻塞显示、项目切换清理与动态策略参数保存。

本轮使用离线/模拟传输验证切换，不调用真实付费模型、不重跑商城结果。客户网关实际Token速度、取消请求后的上游计费和真实长任务完成时间仍需运行后观察。本轮不重建Windows包。

本次最终验证：后端全量526项、前端72项通过，TypeScript及生产构建通过。浏览器在隔离模拟项目确认监视栏折叠/展开、报表区域独立滚动及阈值曲线；模拟数据未加入正式项目。
