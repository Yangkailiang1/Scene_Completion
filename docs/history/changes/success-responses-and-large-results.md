# 成功响应抽取与大项目结果加载修复

## 成功响应

API参数任务分别保留请求参数和成功返回字段。返回字段以 `location=response` 存储，支持明示的类型、必填性及约束；返回消息继承所对应请求的接口身份，输出数据沿用七类数据关注点。

本轮修复接口取片对加粗接口标题、与接口标题同级的成功响应章节的遗漏。明确响应表中的字段由工具补齐；示例值不会被推断成类型、必填或枚举。相邻其他接口与错误响应不参与补齐。

升级不会为旧报告伪造返回关注点。若旧API产物遗漏了响应，应定向更新对应API参数及依赖的交互补全、关注点与场景节点。输出场景仍需独立识别的关注点和证据。

## 结果加载

- 结果首页使用 `GET /api/projects/{id}/results?include_artifacts=false`，先读取用例目录，不扫描产物或生成BDD。
- 图表目录仅在图表／全局视图打开时读取；用例对照只在交互视图读取。
- 管理页面的后台刷新使用 `GET /api/projects/{id}?compact=true`，不扫描审核产物和整个目录；同项目刷新不会重叠堆积。
- 执行图批量读取会话与指导版本，每个产物文件夹只索引一次，避免逐节点重复SQLite连接和目录遍历。
- 目录请求超时或失败提供错误提示和刷新入口。

本地保存项目（1239节点）同环境测量：执行图约2.753秒→0.277秒；轻量结果目录0.027秒，响应约1.9KB；轻量状态快照0.001秒。此结果不是客户Chrome或客户磁盘性能承诺。客户17用例、1661节点数据尚未提供，需要升级后核验。
